
# Day 01 - Network Basics

## Objective
Understand basic networking devices and addressing.

## 1. Network Devices
- Switch: Forwards Ethernet frames using MAC addresses.
- Router: Forwards packets between IP networks.
- Hub: Repeats incoming signals to connected ports.

## 2. MAC Address vs IP Address
- MAC address: Used for Layer 2 frame delivery.
- IP address: Used for Layer 3 addressing and routing.

## 3. Default Gateway
A host uses its default gateway to reach destinations
outside its local IP subnet.

## 4. Subnet Mask
Example:
- CIDR: /24
- Subnet mask: 255.255.255.0

## 5. Verification
Check the PC's IP configuration and test connectivity.

## Key Takeaways
- Switch forwarding uses MAC addresses.
- Routing uses IP addresses.
- A default gateway enables off-subnet communication.
